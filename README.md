# Analog Clock | JavaScript Practice

Analog clock practice using JavaScript Date, timed updates and CSS transforms for hour, minute and second hands.

Part of my JavaScript practice work. Explore my complete projects on [GitHub](https://github.com/awaljanhematyar) or my [developer portfolio](https://hematyar-professional-portfolio.vercel.app/).

[Live demo](https://awaljanhematyar.github.io/clock/)

## Features

- Read the current device time.
- Rotate three clock hands using CSS transforms.
- Account for minutes in the hour-hand position.
- Refresh the display every second.

## Run locally

```sh
git clone https://github.com/awaljanhematyar/clock.git
cd clock
```

Serve the folder using VS Code Live Server and open `index.html`. There is no npm installation or build step. Use a modern browser.
